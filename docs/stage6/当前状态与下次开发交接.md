### 3.3 后端插入 ID 回取方式优化

已完成 `select max(id)` 风险治理：

- 新增公共工具：`services/backend/src/main/java/com/aituan/common/jdbc/JdbcGeneratedKeys.java`。
- 普通新增逻辑统一使用 Spring JDBC `GeneratedKeyHolder` 回取自增主键。
- `user_favorite` 的 upsert 场景改为按唯一键 `(user_id, favorite_type, target_id)` 查询真实 ID。
- 已扫描确认 `services/backend/src/main/java` 下无残留 `select max(id)`。
- 已通过后端 Maven 测试。

详细文档：

- `docs/stage6/分工A-后端插入ID回取优化说明.md`

### 3.4 优惠券库存并发安全优化

已完成限量券领取库存安全增强：

- 领取接口在事务内使用 `for update` 锁定 `coupon_template` 行。
- `issued_qty` 增加改为条件更新：`total_qty = 0 or issued_qty < total_qty`。
- 库存不足时返回业务错误：`优惠券已领完`。
- 新增集成测试 `couponClaimStopsAtTemplateInventoryLimit`，覆盖 `totalQty = 1` 的库存边界。
- 测试过程中同步修正 `JdbcGeneratedKeys` 在 H2 下返回多个生成列的问题，明确只回取 `id` 列。

详细文档：

- `docs/stage6/分工A-后端优惠券并发安全优化说明.md`
