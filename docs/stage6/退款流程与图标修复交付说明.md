## 一、退款流程

### 1.1 数据库迁移

**文件：** `database/migrations/V013__refund_flow.sql`

- `order_main` 表新增 6 个退款快照字段：`refund_status`、`refund_amount`、`refund_reason`、`refunded_at`、`refund_initiator_type`、`refund_initiator_id`
- 新建 `order_refund_record` 表，记录每笔退款流水（退款单号、金额、发起方、原因、时间等）
- 兼容 MySQL 8 与 H2 `MODE=MySQL`，已通过空库迁移验证

### 1.2 后端退款规则

| 场景 | 发起方 | 条件 | 库存释放 |
|------|--------|------|----------|
| 外卖未接单 | 用户 | 已支付 + `merchant_pending` | 是 |
| 服务未使用 | 用户 | 已支付 + 券码 `unused` | 是 |
| 任意已支付未退款 | 商家/后台 | 已支付 + 未退款 | 否 |

退款后状态变更：
- `display_status` → `refunded`
- `payment_status` → `refunded`
- `refund_status` → `succeeded`
- `fulfillment_status` → `refunded`
- 外卖 delivery task 终止
- 非外卖 `order_voucher.status` → `refunded`
- 释放已使用的优惠券
- 预约记录（如有）取消
