- **会员中心** `/member`：当前等级（带等级色头卡）、成长值、距下一级进度条、会员权益列表；已是最高等级时不显示"还需"。
- **优惠券** `/coupons`：可用 / 已用 / 失效 三 Tab；右上「领券中心」入口。
- **领券中心** `/coupons/claim`：可领模板列表，支持领取（防重复点击、成功刷新、失败展示后端原因、已达上限置灰）。

后端会员/优惠券接口与 V009 迁移、seed 演示数据此前已就绪，本次为纯前端对接。

## 4. 数据层重构（json_codec 抽取）

会员/优惠券数据层未塞进已 990 行的 `backend_app_repository.dart`（避免突破"单文件不过千行"），而是：

- 把原文件末尾的 `_string/_map/_int/...` 等解析助手抽为 `core/network/json_codec.dart` 的公开函数（`jsonString/jsonMap/jsonInt/...`），作为唯一实现；
- `backend_app_repository.dart` 保留同名私有委托别名（如 `Map<String,dynamic> _map(v) => jsonMap(v);`），既有调用点全部不变；
- 新建的 `member_repository.dart`/`coupon_repository.dart` 复用 `json_codec` 与 `AppApiClient`，各自独立、高内聚低耦合。

## 5. 后端接口对接

| 页面 | 接口 |
| --- | --- |
| 会员中心 | `GET /api/app/account/member/info` |
| 我的券 | `GET /api/app/account/coupons?status=usable\|used\|expired` |
| 领券中心 | `GET /api/app/account/coupons/available`、`POST /api/app/account/coupons/{templateId}/claim` |

展示串 `discountDesc`/`thresholdDesc`/`validDesc` 直接采用后端产出，前端不重复计算金额规则。均受 `USER` 角色保护，未登录点入口由 `router` 自动跳登录。

> 环境提示：本机当前访问 github.com 被重置，`flutter analyze`/`flutter test`/`flutter build` 在 Flutter 工具启动时会做联网版本检查（`git fetch --tags`）而以 exit 128 失败。这是**网络/环境问题，非代码问题**。规避：给 flutter 命令加全局开关 `--no-version-check`，或在网络恢复后执行。`dart analyze` 走 Dart SDK，不受影响。


### 6.3 打包（D 盘，沿用既有脚本）

打包统一用仓库脚本，源码镜像与缓存/产物均在 D 盘英文路径，构建后自动清理工作目录：

```
powershell -ExecutionPolicy Bypass -File scripts\build\build_android_apk.ps1
```

- 工作目录：`D:\aituan_build\user_app`（脚本结束自动删除）
- pub/gradle 缓存：`D:\aituan_cache\pub`、`D:\aituan_cache\gradle`
- **产物 APK：`D:\aituan_release\apk\aituan-user-debug.apk`**（本次已构建确认）

> 中国网络打包注意：本机用 Clash Verge 代理（`127.0.0.1:7897`）。Gradle/JVM 默认不读系统 HTTP 代理，会直连 `services.gradle.org` / Google Maven 超时。两种解法：①Clash 开 Tun 模式；②给构建注入代理后再跑脚本（验证可用）：
> ```
> $env:GRADLE_OPTS='-Dhttp.proxyHost=127.0.0.1 -Dhttp.proxyPort=7897 -Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=7897'; powershell -ExecutionPolicy Bypass -File scripts\build\build_android_apk.ps1
> ```
> 另：Flutter 工具的版本检查 `git fetch --tags` 离线会以 exit 128 失败，可给 flutter 命令加 `--no-version-check`；`dart analyze` 不受影响。
