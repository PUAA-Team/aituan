# 单元与集成测试分类运行说明

本文档用于说明当前项目按“单元测试 / 集成或 API 测试 / E2E / 静态回归或构建验证”整理后的测试清单、分类脚本和报告位置。现阶段保持低风险整理：不移动已有测试目录、不新增依赖、不批量改 JUnit Tag，分类脚本主要按文件命名和端类型近似归类。

## 1. 分类脚本入口

| 分类 | 脚本 | 默认行为 |
| --- | --- | --- |
| 单元测试 | `scripts/verify/test_unit.ps1` | 运行后端服务层/工具类测试、Flutter 单元测试、商家端和后台端 Vitest 覆盖率测试 |
| 集成/API 测试 | `scripts/verify/test_integration_api.ps1` | 运行后端 MockMvc API、Controller、契约测试；默认跳过 MySQL smoke |
| E2E 测试 | `scripts/verify/test_e2e.ps1` | 包装 `tests/e2e/scripts/run-e2e-local.ps1`，运行 Playwright UC01-UC13 |
| 分类总入口 | `scripts/verify/test_all_classified.ps1` | 默认顺序运行单元测试和集成/API 测试；追加 `-IncludeE2E` 后再跑 E2E |

常用命令：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify/test_unit.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify/test_integration_api.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify/test_all_classified.ps1
```

需要完整验收时再运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify/test_all_classified.ps1 -IncludeE2E
```

如本机已准备 MySQL 8 测试库，可显式开启迁移 smoke：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify/test_integration_api.ps1 -IncludeMysqlSmoke
```

## 2. 单元测试清单

### 2.1 后端单元 / 服务层测试

脚本：`scripts/verify/test_unit.ps1`

当前按类名显式收敛以下测试：

- `FileStorageServiceTest`：文件存储服务边界。
- `TradeGrowthServiceTest`：交易成长值计算。
- `ComplaintServiceTest`：投诉领域服务。
- `DiscoveryServiceTest`：发现页服务聚合。
- `StationMessagePublisherTest`：站内信发布。
- `SupportServiceTest`：客服服务。
- `AiAgentServiceTest`：AI 助手降级和技能编排。
- `InteractionServiceTest`：评价/互动治理服务。

后端命令形态：

```powershell
mvn -B -f services/backend/pom.xml "-Dmaven.repo.local=D:/aituan_cache/m2" "-Dtest=FileStorageServiceTest,TradeGrowthServiceTest,ComplaintServiceTest,DiscoveryServiceTest,StationMessagePublisherTest,SupportServiceTest,AiAgentServiceTest,InteractionServiceTest" test
```

### 2.2 Flutter 用户端单元测试

脚本会在 `apps/user_app` 下执行：


当前测试文件包括：

- 枚举/模型：`shared/enums/business_type_test.dart`、`member_coupon_models_test.dart`。
- 业务 Repository / Model：
  - `features/coupon/coupon_repository_test.dart`
  - `features/complaint/complaint_repository_test.dart`
  - `features/review/review_repository_test.dart`
  - `features/member/member_repository_test.dart`
  - `features/assistant/assistant_repository_test.dart`
  - `features/support/support_repository_models_test.dart`
  - `features/message/message_repository_models_test.dart`
- 业务工具：`features/merchant/takeaway_amount_utils_test.dart`、`features/order/takeaway_fulfillment_text_test.dart`。

本次补齐重点覆盖了投诉、评价、会员和 AI 助手 Repository 的请求路径、请求 body、响应解析、缺省值和弱类型列表解析。

### 2.3 商家端 / 后台端 Web 单元测试

脚本会分别执行：

```powershell
npm --prefix apps/merchant_web --cache D:/aituan_cache/npm run test:coverage
npm --prefix apps/admin_web --cache D:/aituan_cache/npm run test:coverage
```

当前测试文件：

- 商家端：`apps/merchant_web/src/api.test.ts`、`apps/merchant_web/src/pages/LoginPage.test.ts`。
- 后台端：`apps/admin_web/src/api.test.ts`、`apps/admin_web/src/pages/LoginPage.test.ts`。

本次补齐重点覆盖商家端和后台端 API 封装：订单履约、退款、券码、预约、评价治理、投诉处理、平台客服、会员等级、优惠券模板、商家/门店/目录维护等接口路径、method、query 和 body。

## 3. 集成 / API 测试清单

脚本：`scripts/verify/test_integration_api.ps1`

默认运行模式：

```powershell
mvn -B -f services/backend/pom.xml "-Dmaven.repo.local=D:/aituan_cache/m2" "-Dtest=*ApiIntegrationTest,*ApiTest,*ControllerTest,*ContractTest" test
```

当前覆盖范围：

- `AuthApiIntegrationTest`：认证登录、注册、鉴权边界。
- `SecurityBoundaryApiTest`：用户、商家、管理员角色边界。
- `CommonFileControllerTest`：文件上传 Controller。
- `LskyProImageStorageClientContractTest`：第三方图床客户端契约。
- `ComplaintApiIntegrationTest`：投诉列表、详情、提交、补充、治理状态。
- `CouponApiIntegrationTest`：优惠券列表、可用券、领取登录校验。
- `TradeApiIntegrationTest`：交易查询、权限与基础 API。
- `MessageApiIntegrationTest`：消息列表、批量已读、删除。
- `DiscoveryApiIntegrationTest`：发现页首页、模块、搜索响应壳。
- `TradeLifecycleApiIntegrationTest`：外卖订单预览、创建、支付、退款最小成功链路。
- `VoucherBookingApiIntegrationTest`：券码查询/核销/重复核销、预约列表与确认。
- `MerchantCatalogApiIntegrationTest`：商家目录列表、新增商品、上下架、配送规则和权限边界。

MySQL 迁移 smoke 不默认运行，避免本机未准备 MySQL 时阻塞普通分类测试。需要时使用 `-IncludeMysqlSmoke` 单独开启。

## 7. 后续可优化项

- 后端如需更精确地区分单元测试和集成测试，可后续引入 JUnit 5 `@Tag("unit")`、`@Tag("integration")`，并更新 Surefire/Failsafe 配置。
- 当前 Web 覆盖率集中在 API 封装和登录组件，后续如果答辩需要更高覆盖率，可针对核心页面补轻量组件测试。
- MySQL smoke 当前保留为显式开关，适合 CI 或已准备本地 MySQL 8 的环境运行。
