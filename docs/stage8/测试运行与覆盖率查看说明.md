# 测试运行与覆盖率查看说明

## 1. 后端测试

### 1.1 运行全部后端测试和覆盖率检查

在项目根目录执行：

```bash
mvn -B -f services/backend/pom.xml verify
```

该命令会执行：

- 后端单元测试
- 后端 MockMvc / H2 集成测试
- JaCoCo 覆盖率报告生成
- JaCoCo 覆盖率阈值检查

报告位置：

```text
services/backend/target/site/jacoco/index.html
```

### 1.2 单独运行 LskyPro mock contract 测试

```bash
mvn -B -f services/backend/pom.xml -Dtest=LskyProImageStorageClientContractTest test
```

### 1.3 本地运行 MySQL 8 迁移烟测

需要先启动 MySQL 8，并创建数据库与账号：

```text
数据库：aituan_test
账号：aituan
密码：aituan_password
```

然后执行：

```bash
AITUAN_MYSQL_CI_ENABLED=true \
AITUAN_DATASOURCE_URL='jdbc:mysql://127.0.0.1:3306/aituan_test?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false' \
AITUAN_DATASOURCE_USERNAME=aituan \
AITUAN_DATASOURCE_PASSWORD=aituan_password \
mvn -B -f services/backend/pom.xml -Dtest=MysqlMigrationSmokeTest test
```

在 Windows PowerShell 中可改为：

```powershell
$env:AITUAN_MYSQL_CI_ENABLED="true"
$env:AITUAN_DATASOURCE_URL="jdbc:mysql://127.0.0.1:3306/aituan_test?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false"
$env:AITUAN_DATASOURCE_USERNAME="aituan"
$env:AITUAN_DATASOURCE_PASSWORD="aituan_password"
mvn -B -f services/backend/pom.xml -Dtest=MysqlMigrationSmokeTest test
```

## 4. Flutter 用户端测试

### 4.1 获取依赖

```bash
cd apps/user_app
flutter pub get
```

### 4.2 单元测试 / Widget 测试 / 覆盖率

```bash
flutter test --coverage
```

报告位置：

```text
apps/user_app/coverage/lcov.info
```

### 4.3 integration_test 端到端测试

需要 Android 真机或 Android 模拟器。

查看设备：

```bash
flutter devices
```

运行：

```bash
flutter test integration_test -d <android-device-id>
```

例如：

```bash
flutter test integration_test -d emulator-5554
```

注意：

- Chrome Web 设备不支持 Flutter integration_test。
- 当前项目没有 Windows desktop 工程，不能使用 `-d windows` 跑端到端测试。

## 5. CI 查看方式

GitHub Actions 工作流：

```text
.github/workflows/ci.yml
```

触发方式：

- pull request
- workflow_dispatch 手动触发

CI 会上传以下 artifact：

```text
backend-jacoco-report
merchant-web-coverage
admin-web-coverage
user-app-flutter-coverage
```

可在 GitHub Actions 对应 run 页面下载查看。
