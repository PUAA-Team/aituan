# T01-T04 测试体系补齐说明

## 1. 背景

本阶段对照课程测试要求，负责补齐 T01-T04：

| 编号 | 类型 | 课程检查重点 | 本次补齐内容 |
| --- | --- | --- | --- |
| T01 | 单元测试 | 关键类、方法、业务规则、异常分支，且有断言 | 后端 JaCoCo、Web Vitest coverage、Flutter coverage |
| T02 | 集成 / API 测试 | 模块调用、数据库访问、外部接口 | MySQL 8 service container 迁移验证、LskyPro 图床 mock contract |
| T03 | Web 页面测试 | 商家端 / 后台端页面交互 | 商家端、后台端 LoginPage 组件测试 |
| T04 | Flutter 端到端 | APP 页面完整流程 | 新增 integration_test 页面流转测试 |

本次目标是“补少量内容但形成完整测试闭环”，因此覆盖率阈值采用保守基线，保证 CI 可稳定通过，并为后续持续提升覆盖率预留空间。

## 3. T02 集成 / API 测试

### 3.1 真实 MySQL 8 迁移验证

新增文件：

```text
services/backend/src/main/resources/application-mysql-ci.yml
services/backend/src/test/java/com/aituan/MysqlMigrationSmokeTest.java
```

`MysqlMigrationSmokeTest` 使用 `mysql-ci` profile，验证：

1. 当前数据库产品名包含 `MySQL`。
2. Flyway 已成功执行迁移。
3. seed 数据中 `demo_user`、`demo_merchant`、`demo_admin` 三类演示账号落库成功。

该测试通过环境变量控制：

```text
AITUAN_MYSQL_CI_ENABLED=true
```

本地普通 `mvn verify` 不会误连 MySQL；GitHub Actions 中会开启该变量并连接 MySQL 8 service container。

### 3.2 外部接口 mock contract

新增文件：

```text
services/backend/src/test/java/com/aituan/common/file/LskyProImageStorageClientContractTest.java
```

该测试使用 JDK 自带 `HttpServer` 模拟 LskyPro 图床接口，验证外部 HTTP contract：

- 请求方法为 `POST`
- 请求路径为 `/api/v1/upload`
- 请求头包含 `Authorization: Bearer test-token`
- 请求体为 `multipart/form-data` 且包含 boundary
- 表单包含 `file`、`strategy_id`、`album_id`、`permission`
- 能解析 mock 响应中的 `data.key` 和 `data.links.url`

单独运行命令：

```bash
mvn -B -f services/backend/pom.xml -Dtest=LskyProImageStorageClientContractTest test
```

已验证通过。

## 7. 已知限制与后续建议

1. Web 当前覆盖率阈值较低，是因为历史页面较多且原先只有 API 测试。本次已补 LoginPage 页面测试，后续建议按页面逐步补充并上调阈值。
2. 本地 Flutter integration_test 需要 Android 真机或模拟器；不能使用 Chrome Web 设备执行。
3. npm 安装依赖时提示存在 high severity vulnerabilities，本次未执行 `npm audit fix`，避免自动升级依赖造成额外风险。后续可单独安排依赖安全治理。
4. 后端 MySQL smoke test 默认跳过，只有设置 `AITUAN_MYSQL_CI_ENABLED=true` 时才执行，避免本地无 MySQL 时影响普通测试。
