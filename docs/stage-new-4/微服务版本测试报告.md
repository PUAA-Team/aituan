## 1. 测试结论

本轮微服务版本测试围绕 Gateway + A/B/C/D 四个业务微服务展开。测试结果表明，当前微服务验收版已经满足以下工程要求：

1. A/B/C/D 四个业务微服务已按业务能力拆分，Gateway 作为统一外部入口；
2. 五个 Java 应用具备独立构建、独立测试、独立容器镜像和独立 Kubernetes Workload 的验收口径；
3. 公开 API 由 Gateway 统一路由，227 个公开 HTTP 操作按服务唯一归属；
4. 四个业务服务分别使用 `aituan_identity`、`aituan_merchant`、`aituan_trade`、`aituan_platform` 四个逻辑库和独立账号，跨库访问被拒绝，跨 schema 外键数量为 0；
5. 订单、支付、履约、评价、成长值、消息、库存扣减和文件上传等核心跨服务链路已通过 Gateway 串通；
6. UC01–UC13 共 13 个正式业务用例由 15 条 Playwright 端到端场景覆盖，验收记录中全部通过；
7. 微服务 CI/CD 主链路具备“完整测试通过后才部署同一 SHA”的质量门禁；
8. HPA 自动扩缩容、商家商品服务故障隔离与恢复、单体/微服务同条件性能对比均已形成生产或验收环境证据。

需要注意的是，微服务测试报告中的性能结论只适用于已测的三个只读主要接口和当时的测试环境，不能泛化为“微服务天然比单体更快”。

## 7. 跨服务业务链路测试

### 7.1 Acceptance Smoke 结果

`deploy/microservices/acceptance-smoke.sh` 在真实容器和真实 MySQL 环境中完成了跨服务链路验证，自动输出：

```json
{"status":"PASS","gatewayInternalBlocked":true,"requestIdCount":1,"orderId":9002,"reviewId":1,"fileForwardingVerified":true}
```

该 smoke 覆盖：

1. 用户、商家、管理员三种账号经 Gateway 登录；

```text

  -> aituan-microservices-ci
  -> aituan-microservices-deploy
```

## 12. 性能对比结果

### 12.1 测试口径

性能对比使用同一服务器、同一 MySQL、同一业务数据、同一组 3 个只读接口、并发 50、每轮 15000 请求、单体与微服务各 3 轮，并固定 1 副本，避免 HPA 扩容影响对比。

被测接口：

1. 首页；
2. 推荐列表；
3. 门店搜索。

### 12.2 三轮均值

| 指标（三轮均值） | 单体 | 微服务 | 微服务相对变化 |
| --- | ---: | ---: | ---: |
| 吞吐量 | 318.409 req/s | 463.943 req/s | +45.707% |
| 平均响应时间 | 159.643 ms | 107.765 ms | -32.496% |
| P95 响应时间 | 324.870 ms | 238.821 ms | -26.487% |
| P99 响应时间 | 439.406 ms | 328.356 ms | -25.273% |
| 错误率 | 0% | 0% | 相同 |
| 平均 CPU | 148.887% | 172.079% | +15.577% |
| 平均常驻内存 | 545.113 MiB | 1433.684 MiB | +163.007% |
| 峰值常驻内存 | 556.922 MiB | 1444.840 MiB | +159.432% |

### 12.3 结论解释

在本次测试条件下，微服务版本在三个只读主要接口上的吞吐和延迟表现优于单体版本，主要原因是 Gateway 与 B 服务分担了单体 Java 进程的 CPU 热点。代价是多 JVM 带来的常驻内存明显增加。测试报告不得将此结论泛化为所有业务链路，也不能说明微服务在下单、支付、退款等写链路上一定更快。

## 16. 最终评价

根据最新微服务验收材料，爱团微服务版本在测试层面已经形成较完整的质量保证闭环：服务内测试验证业务规则，契约测试验证跨服务接口，数据库边界测试验证数据所有权，E2E 测试验证 UC01–UC13 业务闭环，CI/CD 验证自动交付门禁，Kubernetes、HPA、故障注入和性能对比验证云原生运行能力。

本轮测试的主要结论是：当前微服务验收版满足课程对微服务拆分、微服务 CI/CD、自动扩缩容、依赖故障处理和改造前后性能对比的核心要求；后续重点应放在同一提交 SHA 的最终复验、写链路性能补测、多节点环境验证和长期证据归档。
