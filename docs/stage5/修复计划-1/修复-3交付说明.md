## 已完成修复

### 1. 收货地址手机号校验

- 新增/编辑收货地址时，手机号输入框只允许数字输入，并限制 11 位长度。
- 保存前复用 `Validator.isPhone()` 做 11 位手机号校验。
- 手机号为空、位数不足或格式不正确时，提示“请输入 11 位手机号”，并阻止保存。
- 地址保存接口提交 trim 后的手机号，避免空格导致异常。

### 2. 搜索结果页位置切换入口调整

- 搜索结果页不再在搜索框下额外新增位置切换行。
- 位置切换入口已回到搜索框下第二行原“当前位置”筛选项位置。
- 第二行仍使用横向滚动布局，长地址不会撑破页面。
- 选择收货地址周边时，展示文字优先使用地址的详细地址部分，并做单行省略。
- 切换当前位置或收货地址后，会重新加载搜索结果。

### 3. 商家端分类删除能力

- 商家端分类标签增加删除按钮。
- 点击删除前会二次确认。
- 前端先按当前商品列表提示“分类下存在商品，请先调整商品分类或删除商品”，减少无效请求。
- 后端新增商家分类删除接口：

```http
DELETE /api/merchant/catalog/categories/{categoryId}
```

- 后端采用软删除：`catalog_category.is_deleted = 1`，并同步 `status = 'disabled'`。
- 后端兜底校验：
  - 只能删除当前商家自己门店的分类；
  - 系统分类不允许删除；
  - 分类下存在未删除商品/服务时不允许删除。

### 4. 根路径下载展示页

- 新增纯前端页面源码：`deploy/landing/index.html`。
- 页面部署到域名根路径 `/`，用于展示平台介绍、APP 下载和商家入驻入口。
- 视觉风格采用暖白、深墨、品牌红、浅金配色，不使用蓝紫色渐变。
- 页面为响应式布局，桌面端左右分栏，移动端上下排布。
- 下载按钮指向：`/downloads/aituan-user-server-debug.apk`。
- 商家入驻/商家端入口指向：`/merchant/`。
- 构建脚本 `scripts/build/build_frontends_server.ps1` 已增加 landing 同步步骤，将 `deploy/landing` 同步到 `deploy/artifacts/landing`。
- Nginx 根路径已从跳转商家端改为托管 landing 页面，同时保留 `/merchant/`、`/admin/`、`/downloads/`、`/api/` 和 `/actuator/health`。

### 5. 用户端版本递增

- 用户端版本号已递增为 `1.0.12+13`。
- 关于页展示已同步为 `v1.0.12`。

## 多端迁移调研

已新增独立调研文档：

```text
docs/stage5/修复计划-1/用户端多端迁移可行性调研.md
```

核心结论：

- Web：当前用户端在仓库外临时副本已通过 Flutter Web Debug 构建，基础迁移可行；正式发布前需要补齐上传、HTTPS 定位、宽屏响应式和部署脚本。
- 鸿蒙：不能直接一键迁移；若目标设备支持 Android 兼容运行，可先使用现有 APK；若目标是 HarmonyOS NEXT / OpenHarmony 原生包，需要单独工具链和插件兼容验证。
