# 后台端与商家端本地构建运行教程

## 1. 适用范围

本文说明如何在本机运行两个 Web 管理端：

- 商家端 Web：`apps/merchant_web`，用于外卖订单处理、商品管理、配送规则和接单模式配置。
- 后台端 Web：`apps/admin_web`，用于平台外卖治理、订单详情、配送时间线、人工推进和异常标记。

两个 Web 端都需要连接后端 API。本文只把后端作为前置依赖说明，重点写后台端和商家端的安装、运行、构建与预览。

## 2. 本机约定路径

仓库根目录：

```powershell
C:/Users/lixu/OneDrive/桌面/软工/new
```

Web 工程路径：

```text
C:/Users/lixu/OneDrive/桌面/软工/new/apps/merchant_web
C:/Users/lixu/OneDrive/桌面/软工/new/apps/admin_web
```

建议 npm 缓存放到 D 盘：

```text
D:/aituan_cache/npm
```

## 3. 前置依赖：启动后端 API

两个 Web 端默认请求：

```text
http://localhost:8080
```

如果还没有后端 jar，先构建：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:/Users/lixu/OneDrive/桌面/软工/new/scripts/build/build_backend.ps1"
```

构建成功后运行 demo 后端：

```powershell
$env:SPRING_PROFILES_ACTIVE = "demo"
$env:SERVER_PORT = "8080"
$env:JAVA_HOME = "D:/tools/jdk-17.0.18+8"
$env:Path = "$env:JAVA_HOME/bin;$env:Path"
java -jar "D:/aituan_release/backend/aituan-backend.jar"
```

检查后端是否正常：

```powershell
Invoke-RestMethod "http://localhost:8080/actuator/health"
```

预期返回：

```json
{"status":"UP"}
```

如果后端不是 8080 端口，启动两个 Web 端前要同步设置 `VITE_API_BASE_URL`。

## 4. 商家端 Web

### 4.1 安装依赖

```powershell
$env:npm_config_cache = "D:/aituan_cache/npm"
npm ci --prefix "C:/Users/lixu/OneDrive/桌面/软工/new/apps/merchant_web"
```

如果没有 lock 文件或需要重新解析依赖，可用：

```powershell
$env:npm_config_cache = "D:/aituan_cache/npm"
npm install --prefix "C:/Users/lixu/OneDrive/桌面/软工/new/apps/merchant_web"
```

优先使用 `npm ci`，结果更稳定。

### 4.2 开发模式运行

```powershell
$env:npm_config_cache = "D:/aituan_cache/npm"
$env:VITE_API_BASE_URL = "http://localhost:8080"
npm run dev --prefix "C:/Users/lixu/OneDrive/桌面/软工/new/apps/merchant_web"
```

访问地址：

```text
http://localhost:5174
```

商家端默认账号：

```text

密码：aituan123
```

登录后默认门店 ID 是 `1`，页面顶部可以切换门店 ID。

### 4.3 构建

```powershell

$env:VITE_API_BASE_URL = "http://localhost:8080"
npm run build --prefix "C:/Users/lixu/OneDrive/桌面/软工/new/apps/merchant_web"
```

构建产物目录：

```text

```

### 4.4 预览构建产物

## 7. 如果后端端口不是 8080

例如后端使用 18080：

```powershell
$env:SERVER_PORT = "18080"
java -jar "D:/aituan_release/backend/aituan-backend.jar"
```

两个 Web 端启动前都要改：

```powershell
$env:VITE_API_BASE_URL = "http://localhost:18080"
```

注意：Vite 只在启动时读取环境变量，修改后必须重启 `npm run dev`。

## 8. 常见问题

### 8.1 登录失败

先检查后端健康状态：

```powershell
Invoke-RestMethod "http://localhost:8080/actuator/health"
```

再确认 `VITE_API_BASE_URL` 是否指向后端实际端口。

### 8.2 页面没有数据

确认使用的是 `demo` profile。demo 后端启动时会自动执行 Flyway 和 seed，商家端、后台端都能看到演示订单。

### 8.3 两个 Web 端端口

默认端口：

```text
商家端：http://localhost:5174
后台端：http://localhost:5175
```

如果端口被占用，可在命令后追加 `-- --port 新端口`：

```powershell
npm run dev --prefix "C:/Users/lixu/OneDrive/桌面/软工/new/apps/merchant_web" -- --port 5184
npm run dev --prefix "C:/Users/lixu/OneDrive/桌面/软工/new/apps/admin_web" -- --port 5185
```

### 8.4 不要提交本地构建产物

以下目录不需要提交：

```text
apps/merchant_web/node_modules
apps/merchant_web/dist
apps/admin_web/node_modules
apps/admin_web/dist
D:/aituan_cache
D:/aituan_build
D:/aituan_runtime
```
