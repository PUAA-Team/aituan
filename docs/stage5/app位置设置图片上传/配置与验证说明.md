# Stage5 App 位置与图片上传配置验证说明

## 本地配置文件

后端启动时会读取本地 `.config`，也会兼容从 `services/backend` 目录启动时读取仓库根目录 `../../.config`：

```text
spring.config.import=optional:file:${AITUAN_CONFIG_FILE:.config}[.properties],optional:file:../../.config[.properties]
```

如果 `.config` 不存在，后端按默认配置启动。

首次配置可复制示例：

```bash
cp .config.example .config
```

`.config` 已加入 `.gitignore`，不要提交真实密钥。

## 图片上传配置

### 默认本地上传

```properties
aituan.upload.strategy=local
```

默认目录：

```properties
aituan.upload.root-dir=D:/aituan_runtime/uploads
aituan.upload.public-prefix=/api/common/files
```

上传成功后 `file_asset.storage_type=local`，`public_url` 类似：

```text
/api/common/files/avatar/xxx.jpg
```

### LskyPro 图床上传

```properties
aituan.upload.strategy=lskypro
aituan.upload.lskypro.api-url=https://p.2b.gs/api/v1
# 二选一：已有 Token 就填 token；否则填 email/password 由后端自动调用 /tokens 获取。
aituan.upload.lskypro.token=你的 Bearer Token，不要带 Bearer 前缀
aituan.upload.lskypro.email=你的 LskyPro 邮箱
aituan.upload.lskypro.password=你的 LskyPro 密码
aituan.upload.lskypro.token-url=https://p.2b.gs/api/v1/tokens
aituan.upload.lskypro.strategy-id=
aituan.upload.lskypro.album-id=
aituan.upload.lskypro.permission=1
```

说明：

- 后端会请求 `POST {api-url}/upload`。
- 如果配置了 `token`，优先直接使用；如果没有 `token`，会用 `email/password` 请求 `POST {token-url}` 获取 `data.token` 并缓存在内存中。
- 请求头包含 `Authorization: Bearer <token>` 和 `Accept: application/json`。
- 表单字段包含 `file`，并按配置附带 `strategy_id`、`album_id`、`permission`。
- 返回中的 `data.links.url` 会写入 `file_asset.public_url`。
- LskyPro 配置缺失时会返回“LskyPro 图床配置不完整，请检查 .config”。

## 地图距离配置

### 默认本地估算

```properties
aituan.map.provider=local
```

无需外部 Key，使用商户和用户经纬度进行 Haversine 距离计算，并按经验速度估算预计时间。列表排序也直接使用本地坐标距离，避免批量消耗高德配额。

### 高德 Web 服务

```properties
aituan.map.provider=amap
aituan.map.amap.web-api-key=你的高德 Web 服务 Key
aituan.map.amap.geocode-url=https://restapi.amap.com/v3/geocode/geo
aituan.map.amap.distance-url=https://restapi.amap.com/v3/distance
aituan.map.amap.regeo-url=https://restapi.amap.com/v3/geocode/regeo
aituan.map.amap.route-url=https://restapi.amap.com/v5/direction/electrobike
```

高德 Key 的服务平台选择“Web服务”。本轮高德用于商家保存地址时将文字地址解析为经纬度、App 当前经纬度反查位置名称、以及距离/预计时间估算。附近商家排序仍优先使用本地坐标距离，避免批量消耗高德配额；未配置 Key 或接口调用失败时，后端自动回退本地估算或“当前位置”文案。

## 验证步骤

### 后端默认配置

1. 不创建 `.config` 或保持 `aituan.upload.strategy=local`。
2. 启动后端。
3. 登录 App 后上传头像或调用通用上传接口。
4. 检查返回 `publicUrl` 为 `/api/common/files/...`。
5. 请求发现接口时分别不传和传入经纬度：

```text
/api/app/discovery/stores/search?keyword=汉堡&page=1&pageSize=12
/api/app/discovery/stores/search?keyword=汉堡&page=1&pageSize=12&latitude=39.982&longitude=116.314
```

第二个请求应返回 `estimatedTimeText`。

### LskyPro 配置

1. 复制 `.config.example` 为 `.config`。
2. 设置 `aituan.upload.strategy=lskypro`。
3. 二选一配置授权：填写 `aituan.upload.lskypro.token`，或填写 `aituan.upload.lskypro.email/password` 让后端自动换取 Token。
4. 启动后端并上传图片。
5. 检查返回 `publicUrl` 是否为图床外链。
6. 检查 `file_asset.storage_type` 是否为 `lskypro`。

### App 验证

1. 运行 `flutter analyze`。
2. 运行 `flutter test`。
3. 打包 APK。
4. 手动验证：
   - “我的”页可进入设置和关于爱团。
   - 首页消息按钮可进入消息页。
   - 连续触发提示时新提示覆盖旧提示。
   - 首页定位成功后显示高德反查的位置名称，商户卡片显示“距离 · 约X分钟”。
   - 地址新增/编辑页点击“使用当前位置”后，自动填入省市区、详细地址和经纬度。
   - 外卖结算页切换地址后刷新配送距离和预计送达时间，超出商家可配送范围时禁止提交。
   - 外卖订单在未支付或待商家接单时可修改配送地址，配送中、已完成、已取消不可修改。
   - 模拟器或设备定位不可用时，首页静默使用“北航学院路校区”作为位置，不展示定位失败提示。

### 商家端验证

1. 配送规则页可配置“可配送范围 km”，保存后刷新仍能回显。
2. 门店资料页选择封面后需要点击“保存门店图片”才上传，上传成功后门店封面刷新。
3. 商品/服务弹窗选择图片后点击保存，基础信息先保存，图片上传失败时弹窗保留并提示具体错误，允许重试。
4. 如果使用 LskyPro，确认商品图和门店图 URL 可正常展示，且数据库 `merchant_store.cover_url`、`catalog_item.cover_url` 可保存外链。

## 注意事项

- Android 真机首次定位会弹出系统授权框。
- 模拟器没有定位数据时可能只能验证拒绝或默认展示路径。
- 外部图床和高德 Key 均属于本地私密配置，不写入文档正文和提交记录。
