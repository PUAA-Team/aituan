# 商家后台用户端改进反馈原文

## 记录说明

本文件用于原封不动记录用户在 Stage5-C 后续改进中的反馈和要求，便于后续规划与实施时逐条对照，不遗漏需求。

## 用户原文

几个问题：1. 商家端与后台端做的太简陋了，很多应该有的功能还没做，现在完善这两个端，规划一下需要的功能，以及前端界面重新设计，我说了不要圆角，要大厂控制台的风格，而且很多地方还有bug，你多做点功能。2. 用户端感觉啥也没改啊，新加的订单状态显示太粗糙了，未完成的时候还显示当前履约状态:加一个英文单词，这是应该出现在前端的吗？然后配送履约记录，那里还没有到的地方你为什么要先显示出来？改掉。 3. 用户端地址填写、地址管理这些你都应该做啊，还有别的地方很多逻辑你都没做，都属于外卖的。 4. 完全重构商家端和后台端页面，太丑了而且太不正经了，商家端的门店切换是什么意思？有必要吗，商品管理那里也要可以添加商品，然后编辑点完之后直接弹窗显示修改啊，把手动/自动接单放到配送规则那里。还有很多功能都没做，比如订单查看等等。而且商家端不仅是给外卖服务的，很多东西要和其他的商家可以复用，重新设计，商家端一个账号对应一个商家，为什么还有别的商家的菜品。然后后台端也是，后台端怎么什么功能都没有，比如一些必要的设置、公告等等的可以放在这里。 5. 很多外卖相关功能没有做，模拟配送在哪里，后端现在要提供这些服务，你要知道我们已经进入模块开发，你不要把什么东西都留到最后做。 6. 所有端都是做的成品，你不需要对于系统的描述也放在前端页面上。 7. 商家端和后台端的页面参考网上成熟的后台管理面板，做的可靠性强一点，很多不属于任何一个人分工的后台或者商家端功能你也做了，思考一下要做什么。8. 前端怎么商品或者商店都没有图，应该做成可以上传图片的，上传图片单独放一个文件夹，后续保留接入其他图床接口的可扩展性。商家/后台都可以修改图片，前端用户也可以修改头像，你暂时找点网上图片代替。9。用户端有一些功能你也没有分给任何人，再仔细研究一下。10. 商家端和后台保持可扩展性，你得考虑其他人怎么继续写。 把上面这些话原封不动记录到本地，然后先git add . + commit一次，然后根据我的要求列出完整的改进计划，写成makrdown文档并列出所有详细事项以及方案！！！
