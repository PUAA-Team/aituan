## 3. 会员成长值与每周会员券

### 3.1 成长值规则

- 消费成长值：订单完成后按实付金额向下取整，`1 元 = 1 成长值`；支付成功不再立即增加成长值。
- 评价成长值：保留首次发表订单评价增加 `3` 成长值。
- 退款退还：退款成功后退还该订单曾发放的消费成长值；如因此造成等级下降，已发放的会员周券暂不回收。
- 幂等策略：新增成长值流水 `member_growth_log`，订单完成、订单退款、首次评价均通过唯一来源避免重复加扣。
- 成长值变化后同步 `user_profile.member_level_name`，保证“我的”页和会员中心等级一致。

### 3.2 等级体系

| 等级 | 成长值门槛 |
| --- | ---: |
| 白银会员 | 0 |
| 黄金会员 | 300 |
| 白金会员 | 1000 |
| 钻石会员 | 3000 |
| 红钻会员 | 10000 |
| 黑钻会员 | 30000 |

### 3.3 每周会员券

- 新增迁移：
  - `database/migrations/V016__stage7_member_weekly_coupon.sql`：会员周券规则。
  - `database/migrations/V017__member_growth_log.sql`：成长值幂等流水。
- 新增表：
  - `member_growth_log`：订单完成、订单退款、首次评价成长值流水。
  - `member_weekly_coupon_rule`：等级与券模板规则。
  - `member_weekly_coupon_batch`：用户每周发券批次。
  - `member_weekly_coupon_issue`：批次发券明细。
- 发放方式：打开会员中心、我的优惠券、我的页时懒刷新。
- 幂等策略：同一用户同一自然周只创建一个批次，发券明细使用唯一键避免重复发放。
- 发放结果写入现有 `user_coupon`，继续复用下单抵扣、支付核销和退款释放逻辑。
- 会员周券模板不出现在手动领券列表中。
