# Stage7 总体计划

Stage7 聚焦三件事：用户端体验修复、会员资产闭环、后台端与商家端界面重构。

## 一、第一部分交付范围

- 修复用户端订单详情底部按钮排列与重复操作。
- 精简用户端消息页顶部布局。
- 将用户端版本号跃升到 `1.1.0`。
- 完善会员成长值、会员等级、每周会员券发放规则。
- 完成后台管理端和商家端界面重构设计与落地。

## 二、后续部分

- AI Agent 功能。
- 数据填充与演示数据治理。
- 用户端更多页面视觉升级。
- 消息与客服能力继续完善。

## 三、实施原则

- 先设计再编码，尤其后台端与商家端按重构处理，不做局部美化。
- 不引入不必要新依赖。
- 不使用渐变色。
- 保留真实有用功能，清理重复、无意义或无闭环主入口。
- 用户端界面改动完成后必须重新打包 APK。
