# 小学期后续看板任务项（简版）

> 口径更正：正式业务用例范围为 UC01–UC13。

> 日期：2026-08-31
> 用途：用于 GitHub Projects、CodeArts、TAPD、Gitee 看板等项目管理工具录入任务。
> 口径：本文件只保留适合看板使用的简洁任务项，避免拆得过细。每项任务可以在看板备注里补充负责人、验收证据和链接。

## 1. 看板列建议

建议看板列使用：

```text
待开始 / 进行中 / 联调中 / 已完成 / 阻塞
```

每个任务建议补充：

- 负责人；
- 计划完成时间；
- 对应提交或 PR；
- 测试报告或截图；
- 当前阻塞问题。

## 2. 微服务拆分准备

| 编号 | 任务项 | 建议负责人 | 验收标准 |
| --- | --- | --- | --- |
| MS-01 | 确认微服务拆分统一标准 | 全员 | 服务名、端口、数据库名、接口规范已统一 |
| MS-02 | 创建微服务主分支和四个成员分支 | 全员 | `microservices-main` 和成员开发分支可用 |
| MS-03 | 确认四人分工 | 全员 | 每人负责一个业务微服务，职责清楚 |
| MS-04 | 梳理单体后端待迁移模块 | 全员 | 当前单体包到四个微服务的映射明确 |
| MS-05 | 确认内部接口清单 | 全员 | 服务间调用接口、请求头、幂等规则确定 |

## 5. 数据库拆分

| 编号 | 任务项 | 建议负责人 | 验收标准 |
