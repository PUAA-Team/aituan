## 备注

- 数据库 SQL 的维护入口是 `database/migrations/` 和 `database/seeds/`。
- `services/backend/target/classes/db/...` 与 `services/backend/bin/target/classes/db/...` 中的 SQL 是构建后复制出的产物，不建议直接修改。
