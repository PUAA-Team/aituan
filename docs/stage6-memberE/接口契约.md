# 成员 E 接口契约

> 所有接口返回统一 `ApiResponse<T>`。分页返回 `ApiResponse<PageResponse<T>>`。  
> 时间统一 ISO-8601。  
> 权限：`/api/app/*` 需 user token；`/api/merchant/ops/*` 需 merchant token；`/api/admin/governance/*` 需 admin token。

---

## 1. 用户端 - 评价

### 1.1 GET `/api/app/interaction/reviews/me`
请求：`?page=1&pageSize=20&status=`（status 可空，可选 `published` / `hidden`）  
响应：分页 `ReviewView`

### 1.2 GET `/api/app/interaction/reviews/{id}`
响应：`ReviewView`（含商家回复、有用数、举报状态）

### 1.3 POST `/api/app/interaction/reviews/{orderId}`（已有，需补 labels/imageUrls）
请求体：
```json
{
  "rating": 5,
  "content": "份量足味道好",
  "labels": ["味道好","出餐快"],
  "imageUrls": ["http://..."]
}
```
响应：`ReviewView`

### 1.4 POST `/api/app/interaction/reviews/{id}/helpful`
请求体：空  
响应：`{ "helpful": true, "helpfulCount": 12 }`

### 1.5 POST `/api/app/interaction/reviews/{id}/report`
请求体：
```json
{ "reason": "广告/辱骂/虚假", "detail": "可选补充说明" }
```
响应：`{ "reportId": 33, "status": "submitted" }`

响应：`MerchantReviewView` 分页

### 4.2 GET `/api/merchant/ops/reviews/{id}`
响应：`MerchantReviewView`

## 8. 后台端 - 投诉

### 8.1 GET `/api/admin/governance/complaints`
请求：`?page=1&pageSize=20&status=&category=`  
响应：`AdminComplaintView` 分页

### 8.2 POST `/api/admin/governance/complaints/{id}/accept`
请求体：`{ "remark": "可选" }`  
响应：`AdminComplaintView`（status -> processing）

### 8.3 POST `/api/admin/governance/complaints/{id}/resolve`
请求体：`{ "remark": "处理结果" }`  
响应：`AdminComplaintView`（status -> resolved）

### 8.4 POST `/api/admin/governance/complaints/{id}/close`
请求体：`{ "remark": "可选" }`  
响应：`AdminComplaintView`（status -> closed）

状态机：
```
pending --accept--> processing --resolve--> resolved --close--> closed
                                |                       ^
                                +-----------close-------+
```
非法跃迁返回 `ORDER_STATE_INVALID`。

## 10. 数据视图（DTO）字段

### ReviewView
```
id, orderId, orderNo, orderTitle, storeId, storeName,
rating, content, labels[], imageUrls[],
status, helpfulCount, reportedCount,
replied, replyContent, repliedAt,
createdAt
```

### SupportSessionView
```
id, storeId, storeName, topic, status,
relatedOrderId, lastMessage, lastMessageAt,
unreadCount, createdAt
```

### SupportSessionDetailView
```
session: SupportSessionView,
messages: PageResponse<SupportMessageView>
```

### SupportMessageView
```
id, sessionId, senderType (user/merchant/system),
senderId, content, createdAt
```

### ComplaintView
```
id, ticketNo, orderId, orderNo,
storeId, storeName, category, title, detail,
status, createdAt, lastUpdatedAt
```

### ComplaintDetailView
```
complaint: ComplaintView,
logs: ComplaintLogView[],
evidenceUrls: []
```

### ComplaintLogView
```
id, action (submit/accept/resolve/close),
operatorType, remark, createdAt
```

### MerchantReviewView = ReviewView 但额外加 `userMaskedNickname`（脱敏）

### MerchantSessionView = SupportSessionView 但额外加 `userMaskedNickname`

### AdminReviewView = MerchantReviewView 但额外加 `reportReasons[]`

### AdminComplaintView = ComplaintView 但额外加 `userMaskedNickname`、`acceptOperator`

## 11. 错误码

复用 `com.aituan.common.exception.ErrorCode`，需要的：
- `NOT_FOUND`（评价/投诉/会话不存在）
- `FORBIDDEN`（无权操作）
- `ORDER_STATE_INVALID`（投诉/会话状态非法跃迁、订单未完成不能评价）
- `PARAM_INVALID`（参数缺失/越界）
- `DUPLICATE_SUBMISSION`（重复提交保护，例如同一举报短时间内重复触发）

> 评价幂等回复**不报错**：第二次回复同一条评价时直接返回首次回复结果（200 / code:0），不抛 `DUPLICATE_SUBMISSION`。
