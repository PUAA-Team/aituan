## V009__interaction_governance_init.sql

### 1. `review_helpful` —— 评价"有用"
```sql
CREATE TABLE IF NOT EXISTS review_helpful (
  id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  review_id BIGINT NOT NULL,
  user_id BIGINT NOT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  is_deleted TINYINT NOT NULL DEFAULT 0,
  UNIQUE KEY uk_review_helpful (review_id, user_id)
);
```

### 2. `review_report` —— 评价举报
```sql
CREATE TABLE IF NOT EXISTS review_report (
  id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  review_id BIGINT NOT NULL,
  reporter_user_id BIGINT NOT NULL,
  reason VARCHAR(80) NOT NULL,
  detail VARCHAR(500),
  status VARCHAR(30) NOT NULL DEFAULT 'submitted',  -- submitted/handled/rejected
  handled_by BIGINT,
  handled_at DATETIME,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  is_deleted TINYINT NOT NULL DEFAULT 0,
  KEY idx_review_report_review (review_id),
  KEY idx_review_report_status (status)
);
```

### 3. `review_audit_log` —— 评价审核轨迹
```sql
CREATE TABLE IF NOT EXISTS review_audit_log (
  id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  review_id BIGINT NOT NULL,
  action VARCHAR(30) NOT NULL,           -- pass / hide / restore
  from_status VARCHAR(30) NOT NULL,
  to_status VARCHAR(30) NOT NULL,
  operator_id BIGINT NOT NULL,
  remark VARCHAR(255),
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_review_audit_review (review_id)
);
```

### 4. `support_session` —— 客服会话
```sql
CREATE TABLE IF NOT EXISTS support_session (
  id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  session_no VARCHAR(40) NOT NULL,
  user_id BIGINT NOT NULL,
  store_id BIGINT NOT NULL,
  merchant_id BIGINT NOT NULL,
  topic VARCHAR(120) NOT NULL,
  status VARCHAR(20) NOT NULL DEFAULT 'open',  -- open / closed
  related_order_id BIGINT,
  last_message_id BIGINT,
  last_message_at DATETIME,
  user_unread_count INT NOT NULL DEFAULT 0,
  merchant_unread_count INT NOT NULL DEFAULT 0,
  closed_at DATETIME,
  closed_by_type VARCHAR(20),                  -- user / merchant / system
  closed_by_id BIGINT,
  close_reason VARCHAR(120),
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  is_deleted TINYINT NOT NULL DEFAULT 0,
  UNIQUE KEY uk_support_session_no (session_no),
  KEY idx_support_session_user (user_id),
  KEY idx_support_session_merchant (merchant_id, status),
  KEY idx_support_session_store (store_id)
);
```

### 5. `support_message` —— 客服消息
```sql
CREATE TABLE IF NOT EXISTS support_message (
  id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  session_id BIGINT NOT NULL,
  sender_type VARCHAR(20) NOT NULL,   -- user / merchant / system
  sender_id BIGINT NOT NULL,
  content VARCHAR(1000) NOT NULL,
  message_kind VARCHAR(20) NOT NULL DEFAULT 'text',  -- text / system / template
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  is_deleted TINYINT NOT NULL DEFAULT 0,
  KEY idx_support_message_session (session_id, id)
);
```

### 6. `complaint_ticket` —— 投诉工单
```sql
CREATE TABLE IF NOT EXISTS complaint_ticket (
  id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  ticket_no VARCHAR(40) NOT NULL,
  user_id BIGINT NOT NULL,
  order_id BIGINT,
  store_id BIGINT,
  merchant_id BIGINT,
  category VARCHAR(30) NOT NULL,             -- service / quality / delivery / other
  title VARCHAR(120) NOT NULL,
  detail VARCHAR(1000) NOT NULL,
  evidence_urls VARCHAR(1000),               -- JSON 数组字符串
  status VARCHAR(30) NOT NULL DEFAULT 'pending', -- pending/processing/resolved/closed
  accepted_by BIGINT,
  accepted_at DATETIME,
  resolved_by BIGINT,
  resolved_at DATETIME,
  closed_at DATETIME,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  is_deleted TINYINT NOT NULL DEFAULT 0,
  UNIQUE KEY uk_complaint_ticket_no (ticket_no),
  KEY idx_complaint_user (user_id),
  KEY idx_complaint_store (store_id, status),
  KEY idx_complaint_status (status)
);
```

### 7. `complaint_log` —— 投诉处理日志
```sql
CREATE TABLE IF NOT EXISTS complaint_log (
  id BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  ticket_id BIGINT NOT NULL,
  action VARCHAR(30) NOT NULL,               -- submit/accept/resolve/close
  operator_type VARCHAR(20) NOT NULL,        -- user/admin/system
  operator_id BIGINT,
  remark VARCHAR(500),
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_complaint_log_ticket (ticket_id, id)
);
```

## R__seed_demo_data.sql 补齐（成员 E 模块部分）

在 R__seed 末尾追加幂等块（用 `ON DUPLICATE KEY UPDATE`，不能 `DELETE FROM`）：

1. 在已有的 5 个演示订单上补 4 条已发布评价、1 条被屏蔽评价。
2. 给 2 条评价加商家回复。
3. 1 条评价被举报 2 次（status=submitted）。
4. 4 个客服会话：2 个 open / 2 个 closed，各自有 3–5 条消息。
5. 3 条投诉：1 个 pending / 1 个 processing / 1 个 closed。
6. 5 条审计日志：分别覆盖 user 提交评价 / merchant 回复 / admin 屏蔽 / admin 受理投诉 / admin 解决投诉。

幂等保护：所有 `INSERT INTO ... VALUES` 都加 `ON DUPLICATE KEY UPDATE updated_at = VALUES(updated_at)`，主键用业务唯一键（`session_no` / `ticket_no` / `(review_id, user_id)`）保证。
